Result mix by diff

All MLN swings S5+. Lower diff is better. Hover a column for the share of each result and the expected OBP / SLG at that diff.

Reading the table. xOBP / xSLG are what the league-wide result mix at each of the hitter's diffs would produce. Build gap is actual OPS minus xOPS: positive means their attribute ranges turn diffs into better results than the league mix does. Diff itself is treated as skill, so there is no luck column. Outcomes counted: swings with a recorded diff, excluding intentional walks, auto K/BB, bunts, steals and live-game scrimmages. Hits include 1BWH / 2BWH; walks count toward OBP only; sac flies count as outs. Expected curves are Gaussian-smoothed per diff, then forced to be non-increasing in diff (pool-adjacent-violators) so a better diff never has a lower expected OBP or SLG.

Team summary: hitting and pitching

Own matchup distribution. With Expected from: Own matchup distribution, expected results come from the player's own attributes instead of the league mix: the exact sheet calculator is run for a hitter against every pitcher in MLN that season (weighted by batters faced), and for a pitcher against every hitter (weighted by plate appearances); the result ranges are stacked into that player's own result mix at each diff. In the Simple set that is done with bases empty and no outs (stored in 10-wide diff buckets). In the Game state set every swing is run in its own outs, bases and runner speeds (and as a hit and run where the evidence says one was on), then valued with the same run-value and win-probability tables as the league mix, so xRuns, xWPA and the gaps measure results against what that player's build would give at the diffs he actually got. A pitcher's expectation is the hitters' side of it, as everywhere on this page. The league mix stays the default. Open a hitter and use Matchup curve to see the curve itself.
Game-state mode. Every swing gets a run value from the play log: run expectancy after the play plus runs scored on it, minus run expectancy before it (RE24 matrix). WPA is win probability after minus before from the batting team's side, using the win probability table. The expected versions take the league's result mix at that diff within the same outs and bases state and weight each result's run value and WPA for that exact situation (inning, score, outs, bases) using the runner-advancement table. Runs vs x and WPA vs x are therefore the effect of the hitter's build against the league's mix, with diff treated as skill. Results are kept at full granularity (1BWH, 2BWH, GORA, FC, each DP type, fly vs pop outs and so on); DPRun, TP and LODP are merged into DP because they are too rare to model; 1BWH2 (a less well-hit single with runners on 1st and 2nd: the runner on 1st stops at 2nd) is its own result. The league mix per state is Gaussian-smoothed over diff and shrunk slightly toward the all-states mix restricted to results that occur in that state, so sparse states stay stable. Raise the smoothing width if curves look noisy.

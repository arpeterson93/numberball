Values: b1/b2/b3/b4 (base reached), 0 (out), or blank (stays put).

b1/b2/b3 below are the inverse: WHO ends up standing on that base after the play (B, r1, r2, r3, or blank if empty) - a manual cross-check against the columns above. Not currently read by the game engine (only B/r1/r2/r3 are).

Fielding

ExcludedPositions/DefaultPosition: position codes, e.g. SS,2B / 3B. ThrowOrder*: one character per leg, comma/space/dash all work as separators - h/f/s/t for a real throw to HOME/1B/2B/3B (reconciled against the runner), 1-9 for a cutoff man's own scorecard position number (decorative relay only, never an out) - e.g. fst is a direct 1B-then-2B-then-3B relay, 6h is a throw cut off by the shortstop and relayed home. ThrowOrder_LF/CF/RF are a specific outfielder's own sequence and beat the older, coarser ThrowOrder_OF (any outfielder) when both are set - fill in a specific one only when that outfielder's own throw genuinely differs from the shared default.
